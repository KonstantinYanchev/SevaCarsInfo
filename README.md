# SevaCarsInfo

Seva Cars Info is a modern, eye-catching **front-end-only** informational site for a car company. Built with Next.js, React 19, TypeScript, and Tailwind CSS v4 — no back-end, no server-side logic.

---

## Tech Stack

| Technology | Purpose |
|---|---|
| [Next.js 15](https://nextjs.org/) (App Router) | React framework |
| [React 19](https://react.dev/) | UI library |
| [TypeScript](https://www.typescriptlang.org/) | Type safety |
| [Tailwind CSS v4](https://tailwindcss.com/) | Utility-first styling |
| [Framer Motion](https://www.framer.com/motion/) | Animations |
| [Embla Carousel](https://www.embla-carousel.com/) | Carousels |
| [Lucide React](https://lucide.dev/) | Icons |

> ⚠️ This is a **front-end only** application. There is no back-end, no API routes, and no server-side dependencies.

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Resolve skills (run after cloning)
npx skills install

# 3. Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
