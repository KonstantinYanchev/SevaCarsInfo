# Hero Background Image

## Required Image

Place your hero background image here as `hero-background.jpg`

### Image Specifications

- **Filename**: `hero-background.jpg`
- **Recommended Size**: 1920x1080px or larger (Full HD minimum)
- **Format**: JPG or PNG (JPG preferred for file size)
- **Aspect Ratio**: 16:9 (landscape)
- **File Size**: Under 500KB (optimize for web)

### Content Guidelines

The image should feature:
- **Ford Mustang or similar American muscle car**
- **Grand Cherokee Jeep**
- **Mechanic working on one of the vehicles**
- **Modern automotive garage/shop setting**
- **Good lighting** (preferably well-lit garage with professional tools visible)

### Image Optimization

Before adding the image, optimize it:
1. Use [TinyPNG](https://tinypng.com/) or [Squoosh](https://squoosh.app/)
2. Target file size: 200-400KB
3. Quality: 80-85% (good balance)

### Implementation

Once you have the image:
1. Save it as `hero-background.jpg` in this directory
2. The home page will automatically display it with:
   - **Smokey atmospheric overlays** - Multi-layer slate/gray gradients for depth
   - **Subtle background blur** - 1px blur + brightness reduction keeps focus on content
   - **Center spotlight effect** - Radial gradient keeps content area brighter
   - **Parallax scrolling effect** - Background moves slower when scrolling
   - **Content emphasis** - Backdrop blur and text shadows make content stand out
   - **Enhanced contrast** - Content is the star, background provides atmosphere
